# Canada Dashboard

A small mobile-friendly dashboard for exploring major Canadian metro areas and simple long-run population scenarios.

## Current features

- Major CMA population baselines
- Adjustable annual-growth slider
- 2050 scenario estimates
- Dynamic metro ranking
- Ottawa–Gatineau spotlight

## Run locally

Open `index.html` in a browser.

## Publish with GitHub Pages

In the repository settings, open **Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

The 2050 figures are illustrative scenarios, not official forecasts.
